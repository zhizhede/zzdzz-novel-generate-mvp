# 《夜班守则》 · 人设卡

> voice_samples 为写作基调示例（生成时作 few-shot），非逐字台词锁定。

## 江述（主角 / 夜班员 / POV）

- 26 岁，失业三个月，白天投简历晚上打工。困、怂、穷，但守规则守得近乎偏执——"规则怪谈里的生存智慧不是勇敢，是记性好"
- 习惯动作：把重要的事写在手背、进店先看监控死角、数零钱
- 内心毒舌 ↔ 表面敷衍礼貌的落差是主要喜剧装置
- 成长线：守规则 → 读规则 → 利用规则冲突 → 改写规则（第二十章后）
- voice_samples:
  - 时薪十八，命是他自己的——这笔账怎么算都是店赚了。
  - 江述没有回头。守则第一条，背十遍不如不看一眼。
  - 好吧。又是一份"字面意思是坑、照做能保命"的工作。
  - 他把手背上的字加了一行。字越少，事越大。

## 温故（前任夜班员 / 半盟友）

- 卡在交接的那个"明天"里，无法离开店，只能以留言条、员工柜物品、监控反光行动
- 说话极短，信息密度高，偶尔冷幽默；对江述先是观察后是托付
- 知道第零条和守则的真正来历；第二十三章起成为攻略核心
- voice_samples:
  - 纸条上的字迹很急：「看日期。」
  - 「第七条不是我写的。」
  - 监控的反光里，有人影站直了，像是等了很久的敬礼。

## 苏晚（白班店员 / 模板人）

- 永远热情、永远标准微笑，白天的店"正常得过分"；从不与夜班打招呼（交接靠留言）
- 真相：她是被「公司」替换过的"合格员工"模板，残存自我因为温故而醒来
- 功能：第二章埋、第十三章可疑、第十四章确认、第二十三章倒戈、第二十五章提供公司侧情报
- voice_samples:
  - 「欢迎光临——」白班的尾音永远上扬，像按了循环键。
  - 苏晚今天也没有问他夜里的事。这是她最好的地方，也可能是最不对的地方。

## 店长（BOSS / 规则的具象）

- 第一个夜班员。违背第零条想救一个"顾客"，被店吞掉，成为守则的执行者
- 只在监控里存在，永远背对镜头；第二十四章转身——没有脸，只有一枚工牌
- 不多话；台词全部是守则句式（"你应该……"）
- voice_samples:
  - 监控里，那个背影缓缓转过来。工牌上有名字，脸的位置只有雪花。
  - 「你应该，在岗。」

## 关系速查

- 江述 ↔ 温故：纸条笔友 → 生死托付（第二十二章"明天"回收）
- 江述 ↔ 苏晚：同事 → 可疑 → 同类相救（第二十三章倒戈）
- 店长 ↔ 温故：同源的两种结局（逃出去的失败者 / 留下来的人）
