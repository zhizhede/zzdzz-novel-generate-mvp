# 本地启动（只讲三件事：数据库 / 后端 / 前端）

## 1. 数据库（PostgreSQL 16，docker 容器 `pg-vector`）

```bash
# 起容器（已存在则跳过；它的 restart 策略是 always，stop 约 8 秒会自动回来）
docker start pg-vector

# 直连查询（密码 <本机库口令>，见 novelgen-app/src/main/resources/application-local.yaml）
docker exec pg-vector psql -U postgres -d novel_gen -c "SELECT 1;"
```

- 连接串：`jdbc:postgresql://localhost:5432/novel_gen`，用户 `postgres`，密码 `<本机库口令>`（local profile）。
- 迁移不用手动做：后端启动时 Flyway 自动执行 `db/migration`（V1–V42）。

## 2. 后端（8090）

```bash
# JAVA_HOME 必设（构建与钩子都钉 JDK 21）
export JAVA_HOME="D:\Program\Java\jdk-21"

# 打包（根目录一条命令出全部模块 + 可执行 jar）
mvn -q clean -DskipTests package

# 杀掉旧进程（netstat 行里端口在 LISTENING 之前，别用 grep "LISTENING.*:8090"，永远匹配不上）
netstat -ano | grep 8090 | findstr LISTENING     # 拿到 PID 后：taskkill //PID <pid> //F

# 启动（jar 在 novelgen-app 模块；根目录跑不了 spring-boot:run，父 pom 没有 boot 插件）
"$JAVA_HOME/bin/java" -jar novelgen-app/target/novelgen-app-0.1.0-SNAPSHOT.jar --spring.profiles.active=local > var/web.log 2>&1 &

# 验证：日志出现 Started NovelGenApplication，或
curl -s -o /dev/null -w "%{http_code}" http://localhost:8090/api/llm-nodes   # 401 = 活着（鉴权生效）
```

- 登录拿会话：`curl -s -c var/cookies.txt -X POST http://localhost:8090/api/auth/login -H "Content-Type: application/json" -d '{"username":"admin","password":"<本机口令>"}'`

## 3. 前端（5173）

```bash
cd web
npm install          # 首次或依赖变更时
npm run dev          # 起 Vite，日志重定向：npm run dev > ../var/vite.log 2>&1 &
```

浏览器打开 `http://localhost:5173`。
