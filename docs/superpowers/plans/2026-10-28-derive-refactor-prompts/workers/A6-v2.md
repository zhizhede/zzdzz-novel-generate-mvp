## Validation rules

结构层：

- `beatNarratives`、`skipped` 必须是数组；
- 每个 beat narrative 必须有 `beatKey/goal/knowledgeEffects/stateEffects/threadEffects`；
- `knowledgeEffects/stateEffects/threadEffects/skipped` 缺失按空数组处理；
- `beatRole/chapterNo/seq/storyLayer` 等旧结构字段必须被 schema `additionalProperties=false` 拒绝；
- `StateChangeKind`、`ThreadEffectKind` 未知值必须返回 `SCHEMA_ENUM_INVALID`。

上下文层：

- knowledge effect 中的 character key 必须在 `castKeys`；
- thread effect 的 thread key 必须在 `threadKeys`；
- beat narrative 和 skipped 中的 beat key 必须在 `beatKeys`；
- 同一个 beat key 不得在 narrative 中重复；
- 同一个 beat key 不得同时出现在 narrative 和 skipped；
- goal、fact、detail、reason 不得为空白。

错误必须使用 `ContractViolation`，不得抛 P6 文案。
